인터랙티브 웹 만들기

머릿속 아이디어를, 클릭할 수 있는 웹으로. 코딩이 처음이어도 AI와 함께 기획하고 만들며 나만의 인터랙티브 웹을 완성하는 4시간입니다.

수업이 끝나면, 내 손에 남는 것

나만의 웹 페이지

소개 페이지, 포트폴리오, 작은 아이디어 중 하나를 골라 화면으로 만듭니다.

움직이고 반응하는 인터랙션

버튼 클릭과 애니메이션을 더해 정적인 화면에 나만의 경험을 담습니다.

공유할 수 있는 결과물

완성한 웹을 배포하고 링크로 공유하는 과정까지 경험합니다.

이런 분과 함께하고 싶어요

  • 코딩 경험 없이 첫 웹 페이지를 만들어 보고 싶은 분
  • AI로 콘텐츠를 만들고 실제 웹에 적용해 보고 싶은 분
  • 포트폴리오나 브랜드 아이디어를 직접 구현하고 싶은 분

4시간, 이렇게 만들어요

  1. 14:00–15:00

    아이디어와 화면 기획

    만들고 싶은 웹을 정하고, 콘텐츠와 화면 흐름을 구성합니다.

  2. 15:00–16:00

    AI와 함께 웹 만들기

    AI를 활용해 텍스트와 콘텐츠를 정리하고 기본 화면을 구현합니다.

  3. 16:00–17:00

    클릭과 애니메이션

    사용자 행동에 반응하는 요소를 추가하고 화면을 다듬습니다.

  4. 17:00–18:00

    배포와 결과 공유

    모바일 화면을 확인하고, 웹을 공개해 서로 결과물을 나눕니다.

실습 진행에 따라 세부 순서와 시간은 조정될 수 있습니다.

준비해 주세요

  • 개인 노트북과 충전기
  • ChatGPT 유료 계정 — 수업 전에 로그인을 확인해 주세요.
  • 직접 만들어 보고 싶은 작은 아이디어

오시는 곳

서울 성동구 아차산로 5길 19
KL빌딩 5층, 503호

온라인 수업이 아닌 오프라인 실습 워크숍입니다.

궁금한 점

처음인데 참여해도 되나요?

코딩을 전혀 몰라도 참여할 수 있도록 기초부터 함께 진행합니다. 만들고 싶은 페이지의 아이디어가 있으면 더 좋아요.

어떻게 신청하나요?

신청 문의 버튼으로 이메일을 보내 주세요. 희망 강좌와 이름을 적어 주시면 잔여석과 신청 절차를 안내해 드립니다. 메일 발송만으로 예약이 확정되지는 않습니다.

수강료와 취소·환불은 어떻게 되나요?

수강료는 1회 10만원입니다. 결제 방법과 취소·환불 조건은 신청 문의 시 안내를 확인해 주세요.
